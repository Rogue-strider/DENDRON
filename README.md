# DENDRON 🌳

A powerful dependency graph visualizer for Rust projects.

## Features (Planned)

- 📊 Interactive dependency tree visualization
- 🔄 Circular dependency detection
- 📦 Multi-language support (Cargo, npm, pip)
- 🔍 Security vulnerability scanning
- 📈 Dependency metrics and analysis

## Installation

\`\`\`bash
cargo install dendron
\`\`\`

## Usage

\`\`\`bash
dendron
\`\`\`

## Development

\`\`\`bash
git clone https://github.com/Rogue-strider/DENDRON
cd dendron
cargo build
cargo run
\`\`\`
